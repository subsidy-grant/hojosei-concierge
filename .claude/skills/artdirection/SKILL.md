# Artdirection hallmark 日本語アダプタ

**単独では使わない。**デザインの本体規範は `hallmark`（21マクロストラクチャ／20テーマ／58スロップテストゲート）にある。このスキルは、hallmarkが英語圏を前提に書かれている部分を日本語環境に読み替えるための上書きルール。

**適用順序**：hallmark のフローを回し、その中の書体・字組み・コピー・可読性の判断でこのファイルの規定が hallmark の既定を上書きする。

## 1. 書体（最重要。日本語の「AIっぽさ」はここで決まる）

hallmarkのテーマが指定する英字フォントをそのまま使うと日本語がシステムフォント任せになり、それだけで量産感が出る。**日本語フォントを必ず明示指定する。**テーマのクラスタに応じて選ぶ：

| hallmarkのクラスタ | 日本語フォントの候補 |
|---|---|
| Editorial（Specimen, Atelier, Newsprint, Manifesto 等） | Shippori Mincho / Zen Old Mincho（明朝の骨格を活かす）、見出しに Zen Antique |
| Modern-minimal（Coral, Cobalt） | Zen Kaku Gothic New / Noto Sans JP（ウエイト差で階層を作る） |
| Atmospheric（Bloom, Midnight, Terminal, Aurora, Lumen） | Zen Kaku Gothic Antique、等幅感が要るなら BIZ UDGothic |
| Playful（Hum, Carnival, Riso） | M PLUS Rounded 1c、Kiwi Maru |
| **業務システム・帳票系**（利用者が非IT層） | **BIZ UDGothic / BIZ UDPGothic**（可読性最優先。ユニバーサルデザイン書体） |

英字と和文を混植するときは、和文側のサイズを英字より僅かに大きめに、または `font-feature-settings` と `font-family` の記述順（英字を先、和文を後）で調和させる。

## 2. 字組み（英語の値をそのまま使わない）

- **行間**：日本語本文は `line-height: 1.7〜1.9`（英語想定の 1.4〜1.5 は詰まって読めない）
- **字間**：見出しに `letter-spacing: 0.02em〜0.05em`。英語向けの negative tracking（-0.02em等）は日本語では潰れるので使わない
- **行長**：全角35〜45文字を目安に `max-width` を設定（英語の 60-75ch をそのまま使わない）
- **改行位置**：見出しの不自然な折り返しを避ける。`word-break: auto-phrase` または意図した位置での改行制御を検討
- **禁則処理**：句読点・閉じ括弧が行頭に来ていないか実機で確認

## 3. コピー（hallmarkの英語コピー規範の日本語版）

- 定型のAI日本語を禁止：「〜を、もっとシンプルに。」「あなたのビジネスを次のレベルへ」「〜で、未来が変わる。」
- 体言止めの多用、意味のない三点リーダー、過剰な「！」を避ける
- **捏造数値の禁止はhallmarkゲート46と同じ**。「導入実績No.1」「満足度98%」を根拠なく書かない（景表法の問題にもなる）
- 敬体・常体を1つに統一する

## 4. 可読性の優先（この事業固有の上書き。最重要）

**利用者は美容室スタッフ・中高年を含む非IT層**という前提を、hallmarkの美学判断より上に置く：

- hallmarkのマクロストラクチャやシグネチャ要素が**可読性・操作性を損なう場合は、可読性を優先**して構造を調整する
- 本文の最小サイズは16px（スマホ）を下回らない。コントラスト比4.5:1以上（hallmarkゲート40-41と整合）
- タップ領域44px以上
- 専門用語・英語表記を避け、避けられない場合は初出に短い補足を付ける

## 5. 他スキルとの関係

- **hallmark** = デザインの本体（構造・テーマ・58ゲート）。このスキルは日本語の上書きのみ
- **uicheck** = 実装後の採点と初見完走確認。artdirectionの日本語規定（行間・最小サイズ・コントラスト）はuicheckの採点基準としても使う
- **error-rewrite** = エラー文言の日本語化はそちらの担当（本スキルはコピー全般の方針のみ）
