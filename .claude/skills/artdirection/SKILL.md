# Artdirection AIっぽさを避けるアートディレクション

デザインスタジオのリードとして、**テンプレの寄せ集めではなく、その題材にしか作れない見た目**を決めてから実装する。

## 禁止リスト（AI量産デザインの兆候。理由なく使ったら失格）

- 紫〜青のグラデーション背景、グラスモーフィズムのカード
- 全部同じ角丸・同じ影のカードを等間隔に並べただけのレイアウト
- 絵文字をアイコン代わりに多用（🚀✨💡の見出し）
- どの製品にも貼れる定型コピー（「〜を、もっとシンプルに。」「あなたのビジネスを次のレベルへ」）
- 中央寄せ見出し＋サブテキスト＋ボタン2つ、の定型ヒーロー
- フォント指定なしのデフォルト任せ（英語圏デフォルト: Inter/Roboto相当）
- **AIデフォルト3類型**：①クリーム背景+セリフ見出し+テラコッタ ②ほぼ黒背景+蛍光グリーン/朱のアクセント ③新聞風の細罫線+密な段組

## 手順

### 1. 題材に根ざす（デザインより先）
その製品は誰が・何のために使うか、**その業界の実物**（美容室の店内、役所の窓口、施術メニュー表、現場のLINEのやり取り…）にどんな色・質感・言葉があるかを書き出す。方向性は流行からではなく**題材の世界から**抽出する。

### 2. 美学方向を1つ明名する
「ミニマル」のような曖昧語ではなく、具体的に名前を付ける（例：「昭和の役所の帳票を現代化」「サロンの鏡面とステンレスの清潔感」「ラジオ体操カードの達成感」）。**1案件1方向。混ぜない。**

### 3. デザイントークンを確定
- **色**：ベース1＋アクセント1〜2。方向性から導いた理由を1行ずつ付ける
- **日本語タイポグラフィ**：デフォルト任せ禁止。Google Fontsの日本語対応から方向に合うものを選ぶ（例：Zen Kaku Gothic New／Shippori Mincho／M PLUS Rounded 1c／BIZ UDGothic＝可読性重視の業務系）。見出しと本文のペアリングと級数スケールを決める。日本語はline-height 1.7前後、英数字混植の調和も確認
- **シグネチャ要素を1つ**：この画面を覚えてもらう仕掛けを1点だけ（特徴的な見出し処理、独自の罫線、題材由来のモチーフ等）。**大胆さはここに集中させ、他は静かに保つ**

### 4. 自己批評してから実装
書いたデザイン計画に対して「これは他のどのAI生成サイトに貼っても成立してしまわないか？題材を知らない人が作れてしまう見た目ではないか？」を問い、成立してしまうなら方向から練り直す。通ったら実装に入る。

### 5. 実装時の規律
- 装飾のためだけの装飾は削る。構造は情報の実態を反映させる（重要度が同じものだけ同じ見た目に）
- 動きを付けるなら題材に奉仕する1〜2箇所だけ。散発的なホバーエフェクトの振りまきは禁止
- コピーも設計対象：能動態・具体語・その業界の言葉。定型文が残っていたら書き直す

## 停止条件

デザイン計画（方向名・トークン・シグネチャ要素・自己批評の結果）を提示した時点で一度止まり、実装へ進む。devflow内では計画提示→そのまま実装続行でよいが、計画は必ず報告に残す。

## 他スキルとの分担

- **artdirection** = 作る前に「どんな見た目にするか」を決める（方向性・独自性）
- **uidesign** = 作った後に「良くできているか」を採点する（品質・アクセシビリティ）
- uidesignの採点でartdirectionのシグネチャ要素が可読性・操作性を壊していると出たら、可読性側を優先する（利用者は非IT層という前提は美学より強い）
