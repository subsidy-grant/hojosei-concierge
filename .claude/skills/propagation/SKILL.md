# Propagation 伝播確認ループ

変更した値の**古い方の値**がプロジェクト内に残っていないかを、ゼロになるまで繰り返し確認する。

## 手順

1. 変更内容を確定する：「旧値 → 新値」のペアを列挙（数値は表記ゆれも：カンマ区切り・万円表記・全角半角・英日）。
2. 新値が**あるべき場所**を先に列挙し、すべて更新済みか確認する。
3. プロジェクト全体を旧値とその関連形で検索する（Grepを使用。HTML/JS/MD/JSON/設定ファイルすべて対象）。
4. ヒットを**1件ずつ審査**する。一括置換はしない：
   - 本当に古い値 → 修正
   - 意図的な残存（履歴・変更ログ・例示・移行コード・互換性） → 残す。**理由を記録**
5. 修正したら再検索。**旧値のヒットが「意図的な残存」だけになるまで**繰り返す。

## 停止条件

- 正常終了：最終検索のヒットがすべて「理由付きの意図的な残存」のみ
- 異常停止：同じ旧値が**2ラウンド連続で復活**したら修正をやめ、何が再生成しているか（ビルド生成物・テンプレート・コピー元ファイル等）を特定して報告

## 報告形式

「修正した箇所一覧／意図的に残した箇所と理由／最終検索の結果（コマンドと実行時刻）」の3点セット。最終検索の出力を根拠として添える（記憶で「消えました」と書かない）。
