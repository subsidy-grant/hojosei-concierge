# Firstuser 初見ユーザー検証ループ

**初めて使う人**として製品を触り、中断なしで完走できるまで直す。

## 手順

1. **クリーンセッションを作る**：Cookie・localStorage・キャッシュ・保存ルートなし。HTML系はPlaywright（python3、chromium同梱）で新規ブラウザコンテキストを起動して実際に操作する。LINE系は友だち追加直後の状態を想定し、可能な範囲で実機確認手順を提示する。
2. **本物の入口から開始**：本番URL・公開ページ・QRコードなど、実際のユーザーが入る場所から。開発者しか知らないURLやローカルファイル直開きは不可。
3. **画面に見えている案内だけを頼りに**最後まで進み、つまずきをすべて記録する：
   - 次に何をすればいいか分からない箇所
   - 専門用語・前提知識を要求している箇所
   - 初回だけ発生するエラー（データ未初期化・空状態の画面崩れ）
4. **最悪のつまずき1つ**を、セキュリティ・アクセス制御・製品要件を壊さない**最小変更**で修正する。
5. **セッションを破棄して最初からやり直す。**修正の副作用も初見の目で再確認する。

## 停止条件

- **1回の中断なし完走**を達成（正常終了）
- 安全な修正が存在しない／アクセスがブロックされている／本人の承認が必要 → 状況を記録して停止

## 禁止事項

- 経験者の記憶で補完して「分かるはず」と判断すること
- クリーン化の省略（前回のlocalStorageが残った状態での確認は無効）
- 完走のためにセキュリティ・要件を緩めること

## 報告形式

「辿った経路／見つけたつまずき一覧（深刻度順）／行った修正／完走の証拠（スクリーンショット等、実行時刻付き）／残ブロッカー」。
